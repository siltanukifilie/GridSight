# Reuse and attribution

No repository-wide software licence has been selected by the GridSight Team.
Public availability is not a blanket grant to reuse all code or data. The team
should choose and approve a software licence separately; this cleanup does not
relicense existing work.

Datasets and dependencies retain their own terms. In particular:

| Material | Recorded source terms / status |
| --- | --- |
| KIT measured-power features, summaries and model results | CC BY 4.0; preserve source and transformation attribution |
| Kenya/Nigeria derived operational error study | CC BY-SA 4.0; preserve attribution and applicable share-alike terms |
| GeoNames, selected Google Open Buildings / geoBoundaries / GridFinder / GEP snapshots | Source-specific CC BY 4.0 attribution |
| OpenStreetMap objects and selected OSM-derived layers | ODbL; preserve attribution and applicable database obligations |
| NISR census factual extracts | Limited attributed figures; no general reuse licence confirmed |
| NASA POWER context | Source acknowledgement and product limitations retained |
| Synthetic data and GridSight-authored code | No blanket software/data licence declared in this repository |

This table summarizes recorded provenance; it is not a legal assessment.
Authoritative per-source records are in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md),
the [prepared source manifest](../data/prepared/source_manifest.csv) and
the [data catalogue](../data/README.md).

Do not publish confidential operator records, restricted layers or whole source
reports merely because a public endpoint or a local copy exists. The historical
MININFRA electricity extract is intentionally excluded from GitHub.
