# Development archive

These records preserve decisions and earlier evidence without presenting them
as current product instructions. They contain superseded country scope, UI
descriptions, test counts, paths and deployment status.

- [Development notes](DEVELOPMENT_NOTES.md): historical README.
- [Implementation plan](IMPLEMENTATION_PLAN.md): original and incremental plans.
- [Completion plan](COMPLETION_PLAN.md): earlier deliverable milestone.
- [Decision log](DECISIONS.md): historical assumptions and scope choices.
- [Progress log](PROGRESS.md): dated implementation history.
- [Verification history](VERIFICATION_HISTORY.md): previous tests and limits.

For current review, use the [judge's guide](../JUDGES_GUIDE.md),
[verification record](../TEST_REPORT.md) and [repository README](../../README.md).
